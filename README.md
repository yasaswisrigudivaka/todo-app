# To-Do List App

An interactive, client-side To-Do List built with HTML, CSS and vanilla JavaScript.
Created as part of my Web Development internship at Thiranex.

🔗 **Live demo:** https://yasaswisrigudivaka.github.io/todo-app/

## Features
- Add, view, edit and delete tasks (full CRUD)
- Mark tasks as completed or active
- Filter tasks: All, Active, Completed
- "Clear completed" button and live count of tasks left
- Data saved automatically with `window.localStorage`, so tasks stay after a page reload
- Dynamic DOM elements with delegated event listeners
- Responsive design with dark mode support

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)

## How to Run
Open `index.html` in any browser, or visit the live demo link above.
